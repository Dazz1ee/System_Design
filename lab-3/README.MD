# Запуск
1. Сначало нужно запустить docker-образы
`docker-compose up -d` или если нужны только бд 
`docker-compose up -d auth-db recipe-db`

2. Нужно накатить [схему](schema.sql) для каждой бд. Внутри файла схему для бд разделены комментарием(пример: Для recipe бд )

3. Вставить тестовые данные из [data](data.sql), аналогично разделены комментов для каждой бд

4. В [queries](queries.sql) находятся запросы, разделенные комментом между бд

# Оптимизация
В файле [optimization](optimization.md) описаны анализ плана выполнения запросов
