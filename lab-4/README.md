# Запуск
1. Сначало нужно запустить docker-образы
`docker-compose up -d` или если нужны только бд 
`docker-compose up -d auth-mongo recipe-mongo`

2. Нужно создать [схему и валидацию](/lab-4/validation.js) для каждой бд. Внутри файла схему для бд разделены комментарием

3. Нужно создать [индексы](/lab-4/indexes.js) для каждой бд. Внутри файла схему для бд разделены комментарием

4. Данные для каждой коллекция в файле [data.js](/lab-4/data.js) 

5. В [queries](queries.sql) находятся запросы, разделенные комментом между бд
